# vig cloud kit

Generated by vig's `bin/cloud-kit.mjs`. **Don't edit these files here.** Edit the source in vig and run the sync again. `manifest.json` lists every generated file with its hash, plus the vig commit it came from.

It exists so Claude Code cloud sessions, which only see the cloned repo, get the same dev team that local sessions load from the user-level Claude folder.

What it adds to this repo's `.claude/`:

- `agents/`: senior, review, qa, tech-pm, spec-compliance, a11y-audit, perf-check, architecture-audit, and the Council (critical-thinker, know-it-all, creative-peer, snidely, synthesizer, baseline)
- `skills/`: senior, review-pr, decompose-ticket, design, plan-project, rebase-auditor
- `rules/`: scope-discipline, code-standards, quality-gates, vig-conventions, cloud-github
- `vig/standards/`: the shared React/Next.js standards and the default architecture rules. A file in `.claude/standards/` still overrides them.
- `hooks/secret-guard.sh`: wired in `settings.json`; it runs only in cloud sessions
- `vig/bin/playwright-mcp.sh`: the `playwright` server in `.mcp.json`, for the qa agent

Check for drift from vig:

```bash
node <vig>/bin/cloud-kit.mjs check <this repo>
```
